## 🚀 Cara Menjalankan

1. **Clone repositori ini**
   ```bash
   git clone https://github.com/<username>/Kumpulan_Tugas_Lab_Daspro_261401053_AngelloAdHarvelSitorus.git
   ```

2. **Masuk ke folder repositori**
   ```bash
   cd Kumpulan_Tugas_Lab_Daspro_261401053_AngelloAdHarvelSitorus
   ```

3. **Kompilasi dan jalankan program yang diinginkan**

   Pastikan [Free Pascal Compiler (FPC)](https://www.freepascal.org/) sudah terpasang, lalu jalankan:

   ```bash
   fpc Pertemuan_01/Tugas_01.pas
   ./Pertemuan_01/Tugas_01
   ```

   Untuk **Windows**:
   ```bash
   fpc Pertemuan_01\Tugas_01.pas
   Pertemuan_01\Tugas_01.exe
   ```

   > 💡 Alternatif: buka file `.pas` di **Lazarus IDE** atau **Dev-Pascal**, lalu tekan **Run** (F9).
